# VI-009: Onboarding Quiz

## Summary
Six-step quiz that collects couple data, persists it to Supabase, and
kicks off the initial site generation.

## Background
The quiz is the product's first impression. Every field is input for
the AI prompt, so quality matters. One question per screen keeps the
interaction calm; a cycling loading screen covers the Claude call.

## Work Required
- `src/components/onboarding/QuizForm.tsx` — 6 steps:
  1. Names.
  2. Date + venue.
  3. Style (6 clickable cards).
  4. Vibe.
  5. Events (1..5 rows).
  6. Story + optional cultural background.
- `src/app/onboarding/page.tsx` wraps the form.
- On submit: insert couple + events, call `/api/generate`, redirect
  to `/dashboard`.

## Technical Notes
- Slug: lowercase first names joined with `-`, ASCII only. If taken,
  append 4 random digits.
- Progress dots and back/next navigation.
- Disabled next button when required fields are empty.

## Acceptance Criteria
- [x] All six steps render.
- [x] Cannot advance without required fields.
- [x] Style cards single-select.
- [x] Events: add / remove rows (min 1, max 5).
- [x] Unique slug ensured via a short numeric suffix.
- [x] Couple + events saved to Supabase.
- [x] Loading screen shows during generation.
- [x] Redirect to `/dashboard` on success.
- [x] Error state with retry on failure.

## Dependencies
VI-006, VI-007, VI-008.

## Definition of Done
A brand-new user can complete the quiz and land on `/dashboard` with
a generated site shown in the preview iframe.
