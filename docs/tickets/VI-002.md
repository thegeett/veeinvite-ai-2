# VI-002: TypeScript Types and Interfaces

## Summary
Define every TypeScript interface used across the pipeline — the
contract between the quiz, the API routes, the AI layer, the validator,
and the renderer.

## Background
Strict typing is how we keep the CSS JSON pipeline from breaking. A
single missed field in ContentMap and the skeleton ships with a visible
`{{PLACEHOLDER}}`. One shared `types.ts` file prevents drift between
layers.

## Work Required
- Build `src/lib/types.ts` with `CoupleData`, `WeddingEvent`, `ThemeJSON`,
  `StylesMap`, `ParticleConfig`, `ContentMap`, `ReasoningBlock`,
  `RSVPData`, `ValidationResult`, `BuildSiteParams`.
- Every ContentMap key must match a skeleton placeholder exactly.
- Export everything.

## Technical Notes
- `StylesMap = Record<string, Record<string, string>>`.
- `ParticleConfig.effect` is a union of the five supported strings.
- `weddingDateIso` is the countdown target (ISO timestamp with zone).

## Acceptance Criteria
- [x] `src/lib/types.ts` exists and exports every type named above.
- [x] ContentMap has every key from the skeleton placeholder list.
- [x] File compiles with no TypeScript errors.
