# VI-012: Landing Page

## Summary
Public landing page at `/`. Communicates the value prop and drives
signups.

## Background
The landing page is the shop window. It needs to explain the product
in seconds and get people to click through to signup. The design
feels like a wedding product, not a SaaS template.

## Work Required
- `src/app/page.tsx`:
  - Hero with headline + CTAs.
  - "How it works" 3-step breakdown.
  - Footer with copyright and login link.

## Technical Notes
Dark background, serif display font, ample whitespace. Responsive on
mobile.

## Acceptance Criteria
- [x] Loads at `/`.
- [x] CTA links to `/auth/signup`.
- [x] "How it works" is clear.
- [x] Responsive.
- [x] VeeInvite branding (not Aisle).

## Dependencies
VI-001, VI-008.

## Definition of Done
A first-time visitor can understand the product and click through to
sign up.
