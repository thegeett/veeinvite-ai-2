# VI-004: Renderer

## Summary
Build the rendering pipeline that transforms validated JSON into a
complete, styled HTML file ready to serve to wedding guests.

## Background
The renderer is the assembly line. It takes the skeleton and a
`ValidationResult`-shaped bundle and produces one self-contained HTML
file. The order of operations is critical — structured data must be
injected **last** so real DB values always overwrite AI copy.

## Work Required
- `src/lib/renderer/index.ts` exports:
  - `buildFontUrl(fonts)` — builds a Google Fonts `css2` URL.
  - `buildStylesheet(styles)` — serialises StylesMap to CSS.
  - `buildParticleScript(config)` — returns canvas + JS animation
    block, or empty string for `effect: 'none'`.
  - `injectStyles(skeleton, fontUrl, stylesheet)` — inserts
    preconnect + stylesheet + `<style id="ai-theme">` before `</head>`.
  - `injectContent(html, content)` — replaces every `{{CONTENT_KEY}}`.
  - `injectStructured(html, couple, events)` — replaces every
    `{{STRUCTURED_KEY}}`. Escapes HTML. Always runs last.
  - `buildSite(params)` — orchestrates all six steps.

## Technical Notes
- `injectStructured` must come after `injectContent`. Treat that as
  the safety guarantee — real data always wins.
- All user-provided strings are HTML-escaped before insertion.
- The particle script is plain ES5 so it runs in the guest's browser
  without any build step.

## Acceptance Criteria
- [x] `buildFontUrl` produces a valid Google Fonts `css2` URL with `+` for spaces.
- [x] `buildStylesheet` serialises every selector's properties.
- [x] `buildParticleScript` returns `''` when effect is `none`.
- [x] `buildParticleScript` returns working canvas + JS for each
      non-none effect.
- [x] `injectStyles` inserts the font link and `<style id="ai-theme">` before `</head>`.
- [x] `injectContent` replaces every content placeholder.
- [x] `injectStructured` replaces every structured placeholder and
      escapes user strings.
- [x] `buildSite` runs the steps in the correct order and produces
      HTML with no remaining `{{PLACEHOLDER}}` tokens given complete input.

## Dependencies
VI-002, VI-003.

## Definition of Done
`buildSite()` with valid inputs returns a complete HTML document
with the couple's data visible and no placeholder tokens remaining.
