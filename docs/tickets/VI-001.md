# VI-001: Project Setup, Skeleton, and Documentation

## Summary
Bootstrap the VeeInvite Next.js project, create the HTML skeleton that
is the foundation of every generated wedding site, and establish the
documentation structure that will guide development.

## Background
VeeInvite uses a pre-built HTML skeleton as the structural foundation
for all generated sites. The AI only styles this skeleton via JSON —
it never generates HTML structure. Getting the skeleton right is the
most critical first step.

## Work Required
- Initialize the Next.js 14 App Router project with TypeScript, Tailwind,
  Supabase, and the Anthropic SDK.
- Create `.env.local` from the provided credentials.
- Write the HTML skeleton at `skeleton/wedding-skeleton.html`.
  Layout-only CSS, all placeholders, working JS.
- Establish the `/docs` folder with ARCHITECTURE.md, DECISIONS.md and
  `docs/tickets/`.
- Populate CLAUDE.md and CONTEXT.md.

## Technical Notes
The skeleton must be around 400-600 lines. Every placeholder listed in
the plan must appear in it exactly. Every class name in the glossary
must exist as a hook. JS (countdown, reveal, FAQ, nav scroll, RSVP
submit) must work out of the box.

## Acceptance Criteria
- [x] Next.js scaffolding committed (package.json, tsconfig, next.config,
      postcss.config, tailwind.config)
- [x] `.env.local` present with provided credentials
- [x] `.env.example` present
- [x] `skeleton/wedding-skeleton.html` exists
- [x] Skeleton contains nav, hero, story, events, gallery, rsvp, faq, footer
- [x] All placeholder tokens present verbatim
- [x] All class names present
- [x] JS for countdown, scroll reveal, FAQ accordion, RSVP submit, nav smooth scroll
- [x] Skeleton has zero visual styling (no colors, shadows, fonts)
- [x] CLAUDE.md populated
- [x] CONTEXT.md populated
- [x] docs/ARCHITECTURE.md populated
- [x] docs/DECISIONS.md populated
- [x] docs/tickets/VI-001.md committed

## Dependencies
None.

## Definition of Done
Opening `skeleton/wedding-skeleton.html` directly in a browser shows a
structurally complete but unstyled wedding site with every section
visible and the countdown, FAQ, and reveal JS working.
