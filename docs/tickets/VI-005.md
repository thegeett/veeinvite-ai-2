# VI-005: AI Layer — Prompt and Generation

## Summary
Build the AI integration layer: a prompt builder that sends the
skeleton and couple data to Claude, and helpers that handle the API
call and extract the JSON response.

## Background
The quality of VeeInvite depends on the quality of the prompt. It must
show Claude the skeleton, explain every class, provide couple data, and
specify the exact JSON shape we expect back.

## Work Required
- `src/lib/ai/prompt.ts`:
  - `buildPrompt(skeleton, couple, events)` — initial generation.
  - `buildEditPrompt(skeleton, currentThemeJson, couple, events, instruction)`
    — targeted change that preserves what works.
- `src/lib/ai/generate.ts`:
  - `callClaude(prompt)` — `claude-sonnet-4-5`, max 8000 tokens.
  - `parseThemeJSON(raw)` — strips markdown fences, slices to the
    outermost braces, `JSON.parse` — throws with detail on failure.

## Technical Notes
- System prompt: "You are a wedding website visual designer. Return
  only valid JSON. No markdown fences. No explanation. Just the JSON
  object."
- The full prompt is long (~15k tokens) because it includes the
  skeleton and the glossary. This is fine for the sonnet 4.5 model.

## Acceptance Criteria
- [x] `buildPrompt` includes the full skeleton, the complete class
      glossary, all ContentMap keys, and the forbidden-properties list.
- [x] `buildEditPrompt` includes the current ThemeJSON and the
      instruction.
- [x] `callClaude` uses the Anthropic SDK.
- [x] `parseThemeJSON` handles ```json fences and text around the JSON.
- [x] `parseThemeJSON` throws a descriptive error on bad JSON.

## Dependencies
VI-002, VI-003, VI-004.

## Definition of Done
`callClaude(buildPrompt(...))` returns a string that
`parseThemeJSON()` successfully parses into a ThemeJSON object.
