# VI-003: JSON Validator

## Summary
Build the validation layer that checks every field of Claude's JSON
response before it touches the DOM. Invalid values get safe defaults.
The validator never throws.

## Background
Claude is creative and usually correct, but its output cannot be
trusted blindly. The validator is the safety net between the AI and
the renderer. It protects layout, font loading, and basic safety.

## Work Required
- `src/lib/validator/index.ts` exports:
  - `validateStyles(raw)` — strips forbidden CSS, rejects unapproved
    fonts, rejects dangerous patterns, prunes empty values.
  - `validateFonts(raw)` — allowlist + fallback to `Jost:wght@200;300;400`.
  - `validateParticles(raw)` — clamps count to 0..30, opacity to 0..0.7,
    colors to 4 max.
  - `validateContent(raw)` — merges AI content over defaults.
  - `validateAll(parsed)` — runs all four and returns a `ValidationResult`.

## Technical Notes
- `validateAll(null)` must return a complete `ValidationResult` with
  defaults populated.
- Never rethrow. Wrap each section in a try/catch so one malformed
  value cannot crash the whole validation.
- In development, log warnings and errors to the console.

## Acceptance Criteria
- [x] `validateStyles` strips every property in `FORBIDDEN_PROPERTIES`.
- [x] `validateStyles` rejects font-family values that are not on the
      approved list.
- [x] `validateStyles` rejects values matching `DANGEROUS_PATTERNS`.
- [x] `validateFonts` returns `[DEFAULT_FONT]` when the input is empty
      or not an array.
- [x] `validateParticles` clamps count to 0..30 and opacity to 0..0.7.
- [x] `validateContent` fills in every default for missing keys.
- [x] `validateAll(null)` returns a valid `ValidationResult`.
