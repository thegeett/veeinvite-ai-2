# VI-010: Dashboard

## Summary
Couple dashboard with live site preview, direct data editing, AI chat
editing, and RSVP management.

## Background
The dashboard is where couples spend most of their time. The preview
iframe is the centrepiece; every panel feeds edits into it. Structured
edits are fast (no Claude call); chat edits take longer.

## Work Required
- `src/components/dashboard/SitePreview.tsx` — iframe with reload on
  URL change; full-screen "View live" link; inline loading overlay.
- `src/components/dashboard/StructuredEditor.tsx` — click-to-edit
  fields; posts to `/api/structured`.
- `src/components/dashboard/EditPanel.tsx` — chat-style input and
  history; posts to `/api/edit`.
- `src/components/dashboard/RSVPDashboard.tsx` — summary cards, table,
  CSV export.
- `src/app/dashboard/page.tsx` — server component that loads the
  couple + renders the client shell.

## Technical Notes
- The dashboard is a single-couple view (we pick the first / most
  recent couple for the signed-in user).
- We force the iframe to remount by keying it to `siteUrl`.

## Acceptance Criteria
- [x] Couple data loads on mount.
- [x] Iframe shows generated site.
- [x] Structured edits update the DB without a Claude call.
- [x] Chat edits show a loading state and update the preview.
- [x] RSVPs appear in the table.
- [x] CSV export downloads the right data.
- [x] Site URL copy button works.
- [x] Sign out works.

## Dependencies
VI-006, VI-007, VI-008.

## Definition of Done
Editing a name updates the preview, and a chat edit triggers a visible
redesign.
